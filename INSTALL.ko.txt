BOJ 그룹 연습 티어 표시 — 설치와 API 키 발급 안내
버전: 2026.11.21.5 / 안내 확인일: 2026-11-21

백준 그룹 연습의 문제 목록과 스코어보드에 solved.ac 난이도와 레이팅 상태를 표시하는 개인용 Tampermonkey 스크립트입니다. BOJ 또는 solved.ac의 공식 프로그램은 아닙니다.

표시하는 정보
- 레이팅: 난이도가 있고 레이팅 반영 대상인 문제
- 보류: 기여 부족으로 아직 레이팅을 주지 않는 문제
- 제외: 기타 사유로 레이팅을 주지 않는 문제
- 제외·보류: 기여 부족과 별도 제외 사유가 함께 있는 문제
- 미정: 아직 난이도가 정해지지 않은 문제
- 아이콘에 마우스를 올리면 푼 사람, 전체 기여, 유효 기여, 제외 사유를 확인할 수 있습니다.
- 조회 오류와 인증 오류는 위 상태들과 구분해서 표시합니다.

1. 준비

① PC Chrome에 Tampermonkey를 설치합니다.
   공식 사이트: https://www.tampermonkey.net/
   공식 사이트에서 안내하는 Chrome 웹 스토어 링크를 이용하세요.

② Chrome 확장 프로그램 관리 → Tampermonkey → 세부정보에서
   ‘사용자 스크립트 허용(Allow User Scripts)’을 켭니다.
   Chrome 138 이상에서 제공하는 항목입니다.
   https://www.tampermonkey.net/faq.php?locale=en&q=Q209

③ 자신의 solved.ac 계정을 준비합니다.
   배포자의 계정이나 앱에 팀원으로 초대받을 필요는 없습니다.

2. 스크립트 설치

① 아래 설치 링크를 Chrome에서 엽니다.
   https://raw.githubusercontent.com/planPt/boj-group-practice-tier/main/boj-group-practice-tier.user.js
② Tampermonkey 설치 화면에서 코드와 권한을 확인하고 설치합니다.
③ 설치 화면 대신 코드만 표시되면 Tampermonkey 대시보드 → 유틸리티 → URL에서 설치 링크를 가져옵니다.
④ URL 가져오기가 되지 않으면 새 스크립트에 코드 전체를 붙여넣고 저장합니다.

이전 수동 설치판을 사용 중이라면 기존 스크립트 항목에 새 코드 전체를 붙여넣어 저장하세요.
@name과 @namespace를 유지하므로 같은 항목의 코드만 바꿀 때 저장된 키는 유지됩니다.
새 항목으로 중복 설치하지 말고 기존 항목 하나만 실행되도록 확인하세요.
이번 웹 배포판으로 한 번 갱신하면 이후에는 Tampermonkey의 업데이트 설정에 따라 새 버전을 확인합니다.

3. 자신의 solved.ac API 앱과 키 발급

예전 비공식 v3 API와 달리 공식 v4 API는 앱의 Client ID와 Client Secret이 필요합니다.
이 값들은 백준·solved.ac 계정의 로그인 비밀번호가 아닙니다.

① https://backstage.solved.ac/developer/apps 에 접속하고 자신의 계정으로 로그인합니다.
② ‘새 앱’을 누릅니다.
③ 다음과 같이 이름과 설명을 작성합니다. 같은 문구를 사용해도 됩니다.
   이름: BOJ Group Practice Tier Display
   설명: 개인용 BOJ 그룹 연습 문제의 난이도와 레이팅 상태를 조회합니다.
④ 표시되는 개발자 약관을 직접 읽고, 동의하는 경우 체크한 뒤 ‘만들기’를 누릅니다.
   약관: https://solved.ac/developer-terms
⑤ 앱의 ‘일반’ 탭에서 ‘클라이언트 ID’를 복사합니다.
⑥ 앱의 ‘시크릿’ 탭 → ‘새 시크릿’ → ‘시크릿 만들기’를 선택합니다.
⑦ 발급된 Client Secret을 복사합니다. 이 값은 발급할 때 한 번만 표시됩니다.
   스크립트에 설정하기 전까지 발급 창을 닫지 마세요.
   Client ID 화면이 따로 필요하면 앱 관리 화면을 다른 탭에 열 수 있습니다.

이 스크립트는 공개 문제 정보만 조회하므로 OAuth2 설정이나 Redirect URI 등록은 하지 않습니다.
팀 초대도 필요하지 않습니다. 각자 자신의 앱과 키를 사용합니다.

4. 스크립트에 키 입력

① 자신의 백준 그룹 연습 페이지를 열거나 새로고침합니다.
   지원 주소:
   https://acmicpc.net/group/practice/view/그룹번호/연습번호
   https://www.acmicpc.net/group/practice/view/그룹번호/연습번호
   일반 문제 페이지나 그룹 메인에서는 이 스크립트가 실행되지 않습니다.
② 페이지에 표시되는 ‘API 키 설정’ 버튼을 누릅니다.
   또는 이 백준 탭에서 Tampermonkey 아이콘을 누르고
   ‘solved.ac API 키 설정’ 메뉴를 선택합니다.
   이 메뉴는 코드 편집기의 메뉴가 아닙니다.
③ 첫 입력창에 Client ID, 다음 입력창에 Client Secret을 입력합니다.
④ 잠시 기다리면 문제 옆과 스코어보드에 아이콘과 상태가 표시됩니다.

입력한 키는 스크립트 코드에 덧붙이지 않고 Tampermonkey의 스크립트 전용 저장소에 보관합니다.
같은 스크립트 항목의 코드만 교체하는 경우 기존 키를 계속 사용할 수 있습니다.
스크립트를 삭제하거나 저장소를 지우면 다시 입력해야 합니다.

5. 안 될 때

API 키 설정 메뉴나 페이지 안내가 전혀 안 보이는 경우
- Tampermonkey와 해당 스크립트가 활성화되어 있는지 확인합니다.
- Chrome의 ‘사용자 스크립트 허용’과 백준 사이트 접근 허용 상태를 확인합니다.
- 스크립트 버전이 2026.11.21.5인지, 코드 전체를 저장했는지 확인합니다.
- 백준 ‘그룹 연습 보기’ 페이지에서 새로고침합니다.

‘인증 확인’ 또는 접근 거부가 표시되는 경우
- Client ID와 Secret을 서로 바꾸어 입력하지 않았는지 확인합니다.
- 키가 폐기되었거나 앱이 정지된 상태가 아닌지 앱 관리 화면에서 확인합니다.
- Tampermonkey의 ‘solved.ac API 키 설정’에서 다시 입력합니다.

‘조회 오류’가 표시되는 경우
- 네트워크, solved.ac 서비스 상태, 일시적인 호출 제한 등이 원인일 수 있습니다.
- 잠시 기다린 뒤 ‘실패한 문제만 재시도’ 메뉴를 사용합니다.
- 계속 오류가 나면 문제 번호와 오류 문구만 공유하세요. 비밀키는 보내지 마세요.

‘정보 없음’이 표시되는 경우
- 해당 BOJ 번호에 대응하는 solved.ac 문제 정보를 찾지 못했다는 뜻입니다.
- 기여 부족 보류로 판정한 것이 아닙니다.

6. 키와 사용량에 관해

- 배포 파일에는 배포자의 Client ID나 Secret이 없습니다.
- 자신의 키를 코드에 하드코딩하거나 다른 사람에게 보내지 마세요.
- 이 방식은 개인 브라우저의 Tampermonkey 저장소에 키를 보관합니다.
  서비스의 발급 화면은 서버 보관을 안내합니다. 브라우저 저장은 서버 보관과 같은 보안 수준이 아니며,
  다른 사용자에게 하나의 키를 배포하는 구성에는 적합하지 않습니다.
- 저장한 키 삭제: Tampermonkey 메뉴 → ‘저장한 solved.ac API 키 지우기’.
  이는 로컬 저장값 삭제이며, 서버에서 키를 무효화하려면 Backstage에서 해당 키를 폐기해야 합니다.
- 현재 기본 API 예산은 600단위, 회복은 초당 2단위, 문제 검색은 1회당 3단위입니다.
  앱별 조정 가능하며 초과하면 HTTP 429로 일시 거절될 수 있습니다.
- 이 버전은 5문제씩 묶어 조회하고 요청 간격은 최소 1.6초입니다.
  10문제는 캐시가 없을 때 보통 2회 요청·6단위입니다. 성공한 결과는 5분간 유효하며 새로고침·재방문에도 재사용합니다.
  저장 캐시는 최대 300문제·24시간 보관하고, 오래된 결과는 기존 표시를 유지하며 갱신합니다.
  갱신 중·실패 상태와 마지막 조회 시각은 표시와 툴팁에서 확인할 수 있습니다.
  전체를 다시 조회하려면 ‘전체 문제 정보 새로고침’ 메뉴를 사용하세요.
- 같은 브라우저·같은 스크립트의 저장 결과는 재사용하지만 여러 탭의 동시 요청을 조정하지는 않습니다. 여러 탭·기기에서 같은 키를 쓰면 앱 한도를 공유합니다.
- 키를 교체하거나 지우면 문제 캐시도 초기화됩니다. 오류 재시도는 성공한 문제를 다시 조회하지 않습니다.
- 오류가 난다고 여러 앱을 만들어 한도를 우회하지 마세요.

7. 다른 사람에게 다시 공유할 때

- 저장소 안내 링크 또는 .user.js 설치 링크와 이 안내문만 전달하면 됩니다.
- Tampermonkey 전체 백업을 그대로 전달하지 마세요.
  특히 ‘Include script storage’ 옵션을 켠 내보내기에는 입력한 키가 포함될 수 있습니다.
- 이 버전에는 설치 URL과 자동 업데이트 URL이 설정되어 있습니다.
  업데이트 확인 주기는 Tampermonkey 설정을 따릅니다. 백준에 적용하려면 페이지를 새로고침하세요.
