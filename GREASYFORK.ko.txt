백준 그룹 연습의 문제 목록과 스코어보드에 solved.ac 난이도와 레이팅 상태를 표시합니다. BOJ·solved.ac의 공식 프로그램이 아닙니다.

## 표시 정보
- 레이팅 반영 대상 / 기여 부족 보류 / 기타 사유 제외 / 제외·보류 / 난이도 미정
- 아이콘에 마우스를 올리면 푼 사람 수, 전체·유효 기여 수, 제외 사유 표시
- BOJ 번호와 solved.ac 문제 번호를 judgeIds로 매핑
- 인증 실패·조회 오류는 문제 상태와 별도로 표시

## 설치와 설정
1. Tampermonkey를 설치하고 Chrome 확장 프로그램 세부정보에서 ‘사용자 스크립트 허용’을 켭니다.
2. 이 페이지의 ‘스크립트 설치’ 버튼을 누릅니다.
3. https://backstage.solved.ac/developer/apps 에서 자신의 앱을 만들고 Client ID와 Secret을 발급받습니다. 약관을 직접 확인하고 동의하세요.
4. 백준 그룹 연습 보기 페이지를 새로고침합니다.
5. 페이지의 ‘API 키 설정’ 또는 해당 탭의 Tampermonkey 메뉴 ‘solved.ac API 키 설정’에서 자신의 Client ID와 Secret을 입력합니다.

설정 메뉴는 스크립트 편집기가 아니라 백준 그룹 연습 탭에서 확인합니다. 일반 문제 페이지나 그룹 메인에서는 실행되지 않습니다.

## 키와 개인정보
- 배포 코드에는 작성자의 실제 Client ID·Secret이 없습니다. 각자 자신의 키를 사용합니다.
- 키는 Tampermonkey 스크립트 전용 저장소에 저장하고, solved.ac의 고정 HTTPS API로만 보냅니다. 작성자 서버로 전송하지 않습니다.
- 조회 대상은 문제 정보입니다. BOJ 로그인 쿠키와 풀이 소스는 수집하지 않습니다. 아이콘은 cdn.solved.ac에서 불러옵니다.
- solved.ac의 발급 화면은 서버 보관을 안내합니다. 이 스크립트는 개인 브라우저에 저장하므로 서버 보관과 같은 보안 수준이 아닙니다. 키를 코드에 넣거나 공유하지 마세요.
- ‘Include script storage’를 켠 Tampermonkey 백업은 공유하지 마세요. 키가 포함될 수 있습니다.
- 유출이 의심되면 Backstage에서 키를 폐기하세요. 스크립트 메뉴의 키 삭제는 로컬 저장값만 삭제합니다.

## 요청과 업데이트
- 5문제씩 묶어 조회하고 요청 간격은 최소 1.6초입니다. 성공한 문제 정보는 최대 300문제·24시간 저장하고, 새 접속·새로고침에서는 저장된 정보를 먼저 표시한 뒤 모든 문제를 한 번 조회합니다.
- 뒤로가기·앞으로가기에서는 캐시만 복원하며 추가 조회하지 않습니다. 캐시가 없거나 24시간이 지났다면 새로고침 안내를 표시합니다. 페이지를 켜두거나 탭을 전환해도 주기적 재조회는 하지 않습니다.
- 조회 중에는 기존 티어를 유지하며 ‘갱신 중’을 표시합니다. 갱신 실패 시에도 이전 결과와 ‘갱신 실패’를 함께 표시하며 자동 재시도하지 않습니다. 마지막 조회 시각과 오류는 아이콘 툴팁에서 확인하세요.
- ‘실패한 문제만 재시도’는 실패한 항목만 조회합니다. 모든 항목을 다시 확인할 때는 ‘전체 문제 정보 새로고침’ 메뉴를 사용하세요. 키를 교체하거나 지우면 문제 캐시도 초기화됩니다.
- 저장 결과는 같은 브라우저의 같은 스크립트 항목에서 재사용합니다. 여러 탭의 동시 요청 제어는 하지 않습니다. 여러 탭과 기기는 같은 앱의 호출 한도를 공유하며, HTTP 429 대기 중에는 재시도도 서버 대기 시간을 지킵니다.
- Greasy Fork에서 설치한 버전은 Greasy Fork를 통해 업데이트됩니다. 확인 주기는 Tampermonkey 설정에 따릅니다.
- 기존 동일 스크립트가 있으면 중복 설치하지 말고 기존 항목을 갱신하세요.
